# Attribution

Telegram Forward / Backup Tool is a heavily modified version of [TGCF (aahnik/tgcf)](https://github.com/aahnik/tgcf), originally created by Aahnik Daw with contributions from the TGCF community and distributed under the MIT license. The vendored TGCF package and this repository retain that license.

TGCF supplies the original Telegram forwarding engine, live and history modes, Streamlit interface, and plugin system. Local additions and modifications include Docker-owned per-account schedulers, multi-account assignments and controls, weighted backup queues, a shared dump destination with bulk routing, backup coverage and progress reporting, transactional JSON state, dashboard authentication controls, and recovery for oversized captions, invoices, and empty history entries. See [README](README.md) for the feature list and operation details.

This project does not claim authorship of upstream TGCF and is maintained independently.
