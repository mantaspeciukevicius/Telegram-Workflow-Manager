# Project summary for LinkedIn

Customized and deployed an open-source Telegram forwarding service on an Ubuntu home server. Building on TGCF, the deployment adds Docker-owned multi-account scheduling, history-copy and LIVE controls, pause/resume, persistent progress and a Streamlit operations dashboard. Locked and atomic JSON updates coordinate the UI and workers.

The portfolio focuses on deployment, reliability and operational visibility. The original TGCF project is credited; this is an extension, not an entirely original Telegram engine. Screenshots use synthetic data and contain no private chat identities or account credentials.

Repository: https://github.com/mantaspeciukevicius/message-workflow-manager
